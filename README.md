# AI Code Production-Readiness Review

让“能跑的 AI 生成代码”，变成“敢上线的系统”。

我为使用 Codex工具快速构建 MVP 的团队，提供面向上线决策的代码质量与可靠性审查。

## 我解决什么问题

AI 可以很快生成页面、接口和业务流程，但真正上线前，风险通常藏在跨模块数据流和业务语义里：

- 权限、租户隔离和敏感数据是否真的闭环
- 金额、时间区间、状态机和幂等是否符合业务规则
- 异步任务失败、重试、并发时是否会产生错误状态
- 配置秘密、登录材料和日志是否可能泄露
- 代码是否通过了确定性质量门禁，而不是只在演示环境“能跑”

## 交付方式

1. 确定性检查：类型、Lint、测试、依赖和安全扫描
2. AI 初筛：阅读 diff 与关键路径，标出可疑点，不直接放行
3. 人工判断：聚焦业务语义、跨模块影响和高风险模块
4. 输出一页纸 P0–P3 报告、PR 评论和优先修复清单

这是一项针对性生产就绪审查，不等同于全面渗透测试、合规认证或无限范围的代码重写。

## 脱敏案例：企业社保/公积金系统

这是一个 AI 辅助开发的个人项目案例，覆盖企业管理、人员花名册、社保/公积金申报、异步任务、导入导出和外部接口。

案例展示重点：

- 如何把业务风险分成 P0–P3，而不是堆砌风格问题
- 如何用证据说明边界、触发条件和影响
- 如何把审查结果转换成发布前质量门禁

案例材料已经去除真实凭据、企业信息、内部域名和本地路径。它是能力展示样例，不代表第三方客户项目。
